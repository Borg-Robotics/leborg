# How to Use Pi0.5

**ONLY IN SIM**: open Isaac Lab and load the table environment.

## Borg_ROS

In `borg_ros`, open (up to) two terminals:
- on terminal 1 run the lerobot bridge:
  ```shell
  ros2 launch  borg_vla lerobot_bridge.launch.py
  ```
- **ONLY IN SIM**: on terminal 2 run the robotiq gripper server to publish the `<griper_name>/holding` state:
  ```shell
  ros2 run robotiq_controllers gripper_action_server
  ```

## LeBorg

In `'leborg`, run the policy server and te inference client in two terminals.

#### In Simulation

In simulation, the ROG VRAM is extremely limited. The VLA networks need to be quantized and a flag must enable a more space-efficient usage of the VRAM.

In terminal 1 run the policy server:
```shell
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True python -m lerobot.async_inference.policy_server     --host=0.0.0.0 --port=8080     --pi05_quantization=int8     --pi05_vision_fp16=true
```

In terminal 2 run the inference client:
```shell
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True python scripts/run_inference.py --config_path=configs/pi05.yaml
```

#### On the Real Robot

**TODO**: the Pi0.5 has never been tested on real hardware. It needs to be tested out.

On the real robot, Isaac Sim does not need to run and use VRAM. Therefore, the models can be run without quantization and without saturating the VRAM.

In terminal 1 run the policy server:
```shell
python -m lerobot.async_inference.policy_server     --host=0.0.0.0 --port=8080
```

In terminal 2 run the inference client:
```shell
python scripts/run_inference.py --config_path=configs/pi05.yaml
```
